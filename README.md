# Automation Challenge
## Description
####  This is a 1 month challenge for improve my skills on automation testing and collaboration into other repositories. Its an educational porpouse project.
## Framework and Dependencies 
#### The framework used for this challenge is Selenium, a WebDriver framework that allows testers to simulate user interactions with the browser. It is useful to test user interactions on applications. I consider it the most useful among its competitors because most of the biggest companies in the world use this framework as part of their standards and is the best option to simulate a user interaction environment.
